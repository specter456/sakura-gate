# Sakura Gate · 桜の門
### An Interactive Physics-Based Pearl Poem Curtain

Welcome to my interactive web project! This is an AI-assisted simulation of a traditional Japanese *Noren* (curtain) made of pearls and poetry, hanging in the gate of a magical cherry blossom castle. 

**🎬 Live Demo:** [Click here to enter the Sakura Gate!](https://specter456.github.io/sakura-gate/)

## 🎬 The Inspiration
This project started when I saw a reference video of a hanging cloth of letters reacting to mouse movements. However, the original was a dark, gloomy Chinese gate created using Framer and AI. 

I wanted to recreate that magical, sparkling aesthetic but completely transform it into something soothing and deeply connected to traditional Japanese culture. I took on the role of Creative Director, guiding an AI to build this from scratch using raw code—no drag-and-drop website builders allowed.

## ✨ Features
* **Realistic Cloth Physics:** I asked the AI to make the pearls swing naturally like a heavy fabric curtain, rather than moving like a rigid grid. It implemented gravity and physics based on my suggestions to make it feel natural.
* **Procedural Wind Chimes:** I suggested adding a soothing *furin* (wind chime) sound that triggers when interacting with the pearls. After testing several harsh, robotic beeps, I guided the AI to refine the audio until it became a pure, calming sound.
* **Atmospheric Effects:** I conceptualized the falling sakura petals, flying birds, and twinkling stars to bring the scene to life.
* **Custom Alignment UI:** Because fitting code to an AI-generated background is tricky, I asked for a control panel with sliders, keyboard nudging, and a "Column Remover." This allowed me to manually trim and perfectly align the curtain to the gate's slant.
* **Persistent Memory:** I requested a feature to save my exact alignment and settings, so the gate reopens exactly as I left it without needing readjustment every time.

## 🚧 The Journey & Hurdles Faced
Building this was a massive learning curve in **AI collaboration and UX testing**. Here are some of the challenges I overcame:

* **The .txt Trap:** I started in Notepad and couldn't figure out why my code wasn't running. I learned the hard way that Windows hides file extensions, turning my `index.html` into `index.html.txt`. This pushed me to upgrade to Visual Studio Code, which was a game-changer.
* **The Translation Gap:** My biggest challenge was translating a visual feeling ("make it feel like a heavy, magical curtain") into instructions the AI could understand. When the text looked like a rigid spreadsheet, I had to iteratively test, identify the UX problem, and suggest specific improvements until the AI implemented the correct physics.
* **The Audio Challenge:** My early audio suggestions resulted in harsh, robotic beeps. I had to repeatedly test the output and guide the AI to refine the sound until it became a pure, soothing wind chime.
* **The Alignment Struggle:** I used Bing Image Creator to generate the perfect castle background, but the code-generated curtain wouldn't fit the gate. Instead of guessing numbers, I asked the AI to build a real-time UI panel so I could trim and align the curtain myself.
